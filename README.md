# Rimewall

A browser tower-defense lane-pusher inspired by the classic Warcraft III Wintermaul Wars custom-map loop. Original code and art; no game assets extracted or redistributed.

Play: https://gjl15.github.io/rimewall/

## Suggestions

Have an idea or found a bug? Open an issue here: https://github.com/gjl15/rimewall/issues — one idea per issue. Say what you observed, what you want instead, and how we will know it works. Screenshots and Map builder exports (`wmw-map-sketch.json`, from the in-game Map builder screen) help a lot.

## History

This project was previously called "Wintermaul Wars Remake" and lived at [gjl15/wmw-remake-web](https://github.com/gjl15/wmw-remake-web). That repo has separate history and is no longer updated — `gjl15/rimewall` is the active one.
