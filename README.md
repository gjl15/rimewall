# Rimewall

A dependency-free browser tower-defense lane-pusher built around the classic Wintermaul-style build–maze–defend–send–income loop. The project uses original code and original art; no Warcraft III game assets are extracted or redistributed.

Current public test build: https://gjl15.github.io/wmw-remake-web/

> The public URL currently retains the earlier repository name. Verify that it matches the latest `gjl15/rimewall` `main` branch before cross-device multiplayer testing. Canonical deployment cleanup is tracked in the master backlog.

## Suggestions and bugs

Have an idea or found a bug? Open a focused issue at https://github.com/gjl15/rimewall/issues.

Say what you observed, what you want instead, the steps to reproduce it, and how we will know the change works. Screenshots, phone/browser details, match seeds, and Map Builder exports help.

Use the master backlog for high-level history and ideas. Completed items remain checked and crossed out instead of being deleted.
