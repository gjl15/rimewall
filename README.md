# Wintermaul Wars Remake

A browser remake of the classic Warcraft III Wintermaul Wars custom-map loop. Original code and art; no game assets extracted or redistributed.

Play: https://gjl15.github.io/wmw-remake-web/

## Suggestions

Have an idea or found a bug? Open an issue here: https://github.com/gjl15/wmw-remake-web/issues — one idea per issue. Say what you observed, what you want instead, and how we will know it works. Screenshots and drawpad exports (`wmw-map-sketch.json` from the in-game Draw map screen) help a lot.
